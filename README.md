# 絶オメガ P1 サークルプログラム シミュレーター

非公式の練習用プロトタイプ。ユーザー提供の説明・配置画像・H2（1番）視点動画を参考に作成しています。映像やゲーム画像そのものは配布物に含めていません。

## すぐに試す

`standalone.html` を Chrome / Edge 等で開いてください。インストール不要・外部通信不要です。

開発版はこのフォルダで `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。`index.html` は ES Modules を使うため直接開かず、HTTPで配信してください。

## 操作

- WASD / 矢印：移動
- クリック / タップ：目的地を指定
- Shift：移動速度1.3倍（練習用、実ゲームのリキャスト管理なし）
- 線または持ち主への接触：自動で線を受け取る（キー操作不要）
- Space：一時停止 / 再開

初期値はH2・1番。他のロール・番号、番号ランダム、塔パターン、再生速度、ガイド表示を設定できます。7人は自動操作です。

## 処理仕様

- 番号1〜4は各2名。塔1234 / 線3412。
- 同番号の優先度は H1 > MT > ST > D1 > D2 > D3 > D4 > H2。
- 各回で北から時計回りに塔2方向を並べ、高優先側・低優先側に割り当てます。線は残りの2方向を同じ順に割り当てます。
- 北を基準に±atan(3/12)だけ傾けた4方向のうち2方向に塔、残り2方向へ線を伸ばします。候補は8地点。
- 初回の線の持ち主はランダム。発動後も線は持ち主に残り、次の担当が取得します。
- 取得条件は線分から1.5以内への接触。担当外でも取得します。受け渡し直後にすでに接触している人は、一度離れて再接触するまで取り直しません。取得距離と接触判定は練習用の仮値です。
- 塔の担当違い・踏み忘れ・担当外の入塔・線の受け渡し漏れ・優先度と違う捨て位置・他者の巻き込みで停止します。
- 刻印・最大HP低下を10秒間表示。刻印中の再処理を禁止します。HP、回復、ダメージ量、死の宣告の遅延発動は再現せず、その場で失敗判定します。

## GitHub Pages公開

1. GitHubに新規リポジトリ（例 `omega-circle-simulator`）を作ります。
2. このフォルダの中身をリポジトリ直下へ保存し、`main` にpushします。`.github/workflows/pages.yml` も含めます。
3. リポジトリの Settings > Pages > Build and deployment > Source を **GitHub Actions** にします。
4. Actions の **Deploy simulator to GitHub Pages** を実行します。初回pushの実行が設定前に失敗した場合は再実行します。
5. 成功後に表示されるURLで操作を確認します。

GitHub Pagesの利用可否はアカウントプランとリポジトリの公開範囲に依存します。既存の攻略サイトのファイルは変更しません。

公式手順：https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## 進行タイミング

- 0〜4秒：サークルプログラム詠唱。全員C集合。
- 4秒：番号付与。3番のNPCのみボスへ直進。
- 5秒：初回の塔出現。
- 6秒：線出現、ブラスター8秒詠唱開始。
- 8.5秒：3番以外のNPCがCでの待機を終えて移動。
- 13・21・29秒：次回の塔予兆を黄色で表示（現在の塔も残る）。
- 14・22・30・38秒：塔と線が同時に爆発。2回目以降は詠唱なし。
- 各爆発後、前の線担当NPCはその位置で2.5秒待機してから移動。自分は手動操作で、待機中も操作可能。

## 表示・移動ルールの更新

- 連続する回で同じ塔座標は使いません。同じ方角が含まれる場合は左右の候補を反転します。
- 塔は現在・次回とも黄色。未入塔は薄く、誰かが入塔すると濃く表示します。ガイドOFFでは塔番号を隠します。
- キャラクター本体の表示直径は従来の2倍。接触距離は従来どおりです。
- 全員に線の接触取得を適用。線担当NPCはボス付近で取得し、他の6人が退避してから伸ばします。担当外NPCは外周沿いを移動し、長い線を横切る直前には待機します。

NPCの外周迂回は残り時間に合わせて移動速度を調整します（上限30、練習用）。自分の移動速度は変更しません。
